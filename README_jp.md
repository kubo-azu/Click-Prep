# 🛟 Click-Prep：Click-qPCR用データ前処理ツール (version 1.2.1)

Click-Prepは，qPCR装置から出力された表形式データを，[Click-qPCR](https://kubo-azu.shinyapps.io/Click-qPCR/)の標準入力形式へ変換するR/Shinyアプリケーションです。遺伝子発現およびDNAコピー数の相対定量ワークフローに対応します。

[English user guide](README.md)

Click-Prepでは，装置出力のインポート・列のマッピング・実験群の割り当て・テクニカルレプリケートの確認・平均Cq値の計算・複数qPCRプレートから得られた互換性のあるデータセットの結合を，すべてブラウザ上で行えます。公開版は <https://kubo-azu.shinyapps.io/Click-Prep/> から利用でき，ローカルインストールは不要です。

## 🌟 主な機能

- **柔軟なファイルインポート：** `.csv`，`.txt`，`.tsv`，`.xls`，`.xlsx`ファイルを読み込めます。列ヘッダーより上にある装置由来のメタデータ行を除外できます。
- **インタラクティブな列マッピング：** 装置固有の列を，必須フィールドの`sample`，`group`，`gene`，`Cq`へマッピングします。
- **実験群の手動割り当て：** 装置出力にgroup列がない場合，アプリ上で実験群を定義し，サンプルへ割り当てられます。このワークフローでは，sample・target・Cqに相当する3列があれば入力できます。
- **レプリケート測定値の手動確認：** レプリケート単位の測定値を表示し，選択した行を除外できます。Click-Prepは外れ値を自動検出・分類しません。
- **平均Cq値の計算：** 保持されたCq値について，`sample`–`group`–`gene`の組み合わせごとに算術平均を計算します。
- **検証付きCSV結合：** 必須列と値を検証したうえで，複数プレート由来の平均Cqデータなど，互換性のあるフォーマット済みCSVファイルを結合します。
- **Click-qPCR用CSV出力：** `sample`，`group`，`gene`，`Cq`の4列からなる標準CSVを出力します。

`gene`フィールドには、遺伝子発現解析では遺伝子名を，DNAコピー数解析では標的ゲノム領域名を格納できます。

## 📖 ワークフロー

アプリケーションは4つのタブで構成されています。

### Introduction

ワークフローの概要とデータの取り扱いに関する情報を表示します。

### Import and Column Mapping

1. qPCR装置の出力ファイルをCSV，TXT，TSV，XLS，またはXLSX形式でアップロードします。
2. 列ヘッダーより上に装置由来の情報がある場合は、**Skip first N rows (metadata)**で除外する行数を指定します。
3. 入力ファイルの列を`sample`，`group`，`gene`，`Cq`へマッピングします。
4. group情報がない場合は，**[Assign groups manually]**を選択し，実験群を定義してすべてのサンプルへ割り当てます。
5. フォーマット後のプレビューを確認します。この時点でレプリケート単位の標準CSVをダウンロードできます。

### Manual Data Review and Mean Cq Calculation

1. テーブルに表示されたレプリケート単位の測定値を確認します。
2. 指定したデータ行を選択して除外することが可能です。
3. 必要に応じて，除外後のレプリケート単位データをダウンロードします。
4. **Calculate Mean Cq**をクリックし，`sample`–`group`–`gene`の組み合わせごとに平均値を計算します。
5. Click-qPCRで解析するための平均Cqデータセットをダウンロードします。

Click-Prepは，外れ値の自動判定や，測定値が実験上の品質基準を満たすかどうかの判定を行いません。除外理由の記録はユーザーの責任で行ってください。また，テクニカルレプリケートを独立したバイオロジカルレプリケートとして扱わないでください。

### Combine Formatted CSV Files

1. 互換性のあるフォーマット済みCSVファイルを1つ以上アップロードします。
2. 読み込まれたファイル名と結合後のデータプレビューを確認します。
3. 結合したCSVファイルをダウンロードします。

すべてのファイルには`sample`，`group`，`gene`，`Cq`の4列がこの順序で含まれている必要があります。平均Cqデータとレプリケート単位データを混在させないでください。

## 入出力形式

| 列 | 説明 |
|---|---|
| `sample` | サンプル識別子。結合するデータセット全体で，生物学的サンプルを一意に識別できる名前を推奨します。 |
| `group` | 実験条件または比較群。 |
| `gene` | 標的遺伝子または標的ゲノム領域。 |
| `Cq` | 数値形式のquantification cycle値。 |

## 重要な適用範囲と制限事項

- Click-Prepが処理するのは表形式のCq出力です。生の蛍光データや増幅曲線は処理しません。
- 装置固有のqPCR実験ファイル，RDML/XMLファイル，レポートファイルは直接読み込めません。装置ソフトウェアから，サンプル識別子，標的名，Cq値を含むコンマ区切りCSV，タブ区切りTXT/TSV，またはXLS/XLSX形式で出力してください。
- 増幅効率，融解曲線，各種コントロール，referenceとtargetの適切性，アッセイの妥当性は評価しません。
- 外れ値の自動検出や除外閾値の決定は行いません。

## 🔒 データの取り扱いとプライバシー

アップロードされたデータは，アクティブなアプリケーションセッション内で処理されます。Click-Prepは，アップロードされたqPCRデータを永続的なアプリケーションストレージへ意図的に書き込みません。アプリケーションが作成した一時ファイルは，不要になった時点またはセッション終了時に削除されます。

Click-Prepは，アップロードされたqPCRデータを第三者へ意図的に送信しません。ただし，公開版の利用には，ホスティング事業者が定めるデータ処理およびログに関するポリシーも適用されます。機密情報，臨床情報，規制対象情報などを扱う場合は，関連ポリシーを確認し必要に応じて承認された環境でローカル版を実行してください。

## ローカルインストール

再現性のあるローカル実行には，R 4.6.1，Git，および`renv`を使用します。RStudioは任意ですが，プロジェクトを開いて実行する場合に便利です。

### 1. リポジトリをクローンする

ターミナルで次のコマンドを実行します。

```sh
git clone https://github.com/kubo-azu/Click-Prep.git
cd Click-Prep
```

### 2. R 4.6.1でプロジェクトを開く

RStudioを使用する場合は，クローンしたフォルダ内の`Click-Prep.Rproj`を開きます。複数のRバージョンを管理している場合は，R 4.6.1が選択されていることを確認してください。

Rコンソールでは次のコマンドで使用中のバージョンを確認できます。

```r
R.version.string
```

### 3. パッケージ環境を復元する

Rコンソールで次のコマンドを実行します。`renv`が未インストールの場合のみ，最初にインストールします。

```r
if (!requireNamespace("renv", quietly = TRUE)) {
  install.packages("renv")
}
renv::restore()
```

この操作により，`renv.lock`に記録されたパッケージがプロジェクト専用ライブラリへインストールされます。

### 4. Click-Prepを起動する

復元が完了したら，Rコンソールで次のコマンドを実行します。

```r
shiny::runApp()
```

表示されたローカルURLをブラウザで開きます。RStudioでは通常，Viewerまたはブラウザが自動的に開きます。

### GitHubから直接実行する簡易方法

リポジトリをクローンせずに試す場合は，次の方法でも起動できます。

```r
if (!requireNamespace("shiny", quietly = TRUE)) {
  install.packages("shiny")
}
shiny::runGitHub("kubo-azu/Click-Prep")
```

`shiny::runGitHub()`は`renv.lock`に記録されたパッケージ環境を自動復元しないため，再現性を重視する場合は，上記のクローンと`renv::restore()`を用いる方法を推奨します。

### ローカル実行時のトラブルシューティング

アプリが起動しない場合や，プロジェクトライブラリと`renv.lock`の不一致が表示される場合は，R 4.6.1が有効になっていることを確認し，次を実行します。

```r
renv::restore()
renv::status()
```

`renv`自体が不整合と表示される場合は，次を実行してRを再起動した後，もう一度`renv::restore()`を実行してください。

```r
renv::restore(packages = "renv")
```
